# Mondoo Community

Welcome to the Mondoo community repo! This repo contains the default templates for all of our GitHub projects.

- [Architecture Decision Records](docs/adr/README.md) - the ADR template and process every Mondoo project uses.
- [GitHub Actions](actions) - shared composite actions.
- Issue templates and community health files applied across the organization.

If you'd like to make a change, see our [Contributing Documentation](CONTRIBUTING.md).
